# 销售数据管理规范

| 属性 | 内容 |
|------|------|
| 文档编号 | SALES-2024-002 |
| 版本号 | v2.1 |
| 生效日期 | 2024年1月1日 |
| 适用范围 | 销售部、各业务部门销售相关岗位 |
| 制定部门 | 销售管理部 |
| 最后修订 | 2025年9月20日 |

---

## 第一章 总则

### 第一条 目的
为规范销售数据的记录、采集、存储和质量管理，确保销售数据的真实性、完整性和可追溯性，为经营决策提供可靠的数据支撑，制定本规范。

### 第二条 适用范围
本规范适用于销售部全体人员的销售数据录入、订单管理、客户信息维护和业绩统计等数据相关活动。

### 第三条 数据管理原则
1. **真实准确**原则：所有销售数据必须如实记录，严禁虚报、漏报。
2. **及时录入**原则：订单完成后 24 小时内完成系统录入。
3. **可追溯**原则：每笔销售记录须关联销售员、产品、客户三要素。

---

## 第二章 销售数据字段标准

### 第四条 必填字段
每条销售记录必须包含以下字段：

| 字段名称 | 说明 | 校验规则 |
|---------|------|---------|
| 工号 | 销售员工编号 | 须与 HR 系统一致 |
| 销售员 | 销售员姓名 | 不能为空 |
| 部门 | 所属部门 | 须为公司有效部门 |
| 日期 | 交易日期 | 不能为未来日期 |
| 订单金额（元） | 含税金额 | 须 > 0 |
| 订单数 | 该笔交易包含的订单数量 | 须为整数且 ≥ 1 |
| 产品 | 产品名称 | 须为公司在售产品 |
| 客户 | 客户名称 | 须为系统中已登记客户 |

### 第五条 订单金额分级
1. 小额订单：单笔金额 < 5000 元。
2. 普通订单：单笔金额 5000-50000 元。
3. 大额订单：单笔金额 50000-200000 元。
4. 特大订单：单笔金额 > 200000 元，需销售总监审批确认。

### 第六条 订单金额异常判定标准
1. 单笔订单金额 > 500000 元：自动标记为异常，需提供合同扫描件核验。
2. 单笔订单金额超过该销售员近 3 个月均值的 5 倍：标记为可疑异常，需直属上级确认。
3. 单笔订单金额超过部门月均值的 10 倍：标记为极端异常，需销售总监审核。

## 第三章 销售数据质量管理

### 第七条 质量分评估
销售数据质量分按以下维度加权计算：
1. 字段完整性（35%）：必填字段是否全部填写。
2. 数据准确性（35%）：金额、日期等数值是否在合理范围。
3. 录入及时性（20%）：是否在 24 小时内完成录入。
4. 关联一致性（10%）：销售员、客户、产品信息是否与其他系统一致。

### 第八条 质量分等级
1. ≥0.9：优秀，数据可直接用于分析。
2. 0.7-0.9：良好，可能存在个别字段缺失。
3. 0.5-0.7：待改进，需数据管理员复查。
4. <0.5：不合格，退回重新录入。

### 第九条 数据月度校验
每月5日前，销售管理部对上月销售数据进行统一校验：
1. 与财务系统对账，核实订单金额一致性。
2. 异常数据清单发至各销售组长确认。
3. 确认无误后数据锁定，锁定后不可修改。

## 第四章 产品与客户信息管理

### 第十条 在售产品目录
公司当前在售产品：

| 产品 | 类型 | 单价区间（元） |
|------|------|--------------|
| 产品A | SaaS 标准版 | 1000-5000 |
| 产品B | SaaS 专业版 | 5000-20000 |
| 产品C | 企业定制版 | 20000-100000 |
| 产品D | 咨询服务 | 10000-80000 |

### 第十一条 客户编码规则
1. 签约客户使用 "客户Alpha/客户Beta/客户Gamma/客户Delta" 四级分类编码。
2. 潜在线索客户以 "L-" 开头编码，如 "L-202511001"。
3. 所有客户需在 CRM 系统中登记，包含客户名称、等级、合同金额、联系电话、跟进日期。

## 第五章 大促期间特别规定

### 第十二条 大促定义
1. 双11大促：每年 11月1日至11月15日。
2. 618大促：每年 6月1日至6月18日。
3. 年终大促：每年 12月10日至12月25日。
4. 其他由公司统一安排的促销活动另行通知。

### 第十三条 大促期间数据管理
1. 大促期间订单量激增，数据录入时效要求放宽至 48 小时内完成。
2. **大促期间的订单金额可能远超历史均值，此期间的异常标记需结合"是否大促"标签综合判断。**
3. 大促结束后 5 个工作日为数据集中清理期。

---

## 第六章 异常数据处理流程

### 第十四条 自动异常检测
系统使用统计学方法自动检测销售数据异常：
1. 按产品和部门分组，计算订单金额的 Q1、Q3 和 IQR。
2. 超过 Q3 + 1.5 × IQR 的订单标记为"候选异常"。
3. LLM 对候选异常进行初步判定，生成异常原因说明。
4. 人工审核确认或驳回异常标记。

### 第十五条 人工审核标准
1. 大促期间的订单金额异常——通常判定为"业务合理波动"，建议解除异常标记。
2. 新客户首单大额——需验证合同和付款凭证后确认。
3. 老客户异常大单——需核实是否为续费/增购/合并开票。

### 第十六条 常见异常原因分类
| 原因分类 | 说明 | 处理方式 |
|---------|------|---------|
| 大促冲量 | 双11/618期间集中下单 | 标记为正常 |
| 大客户签约 | 新签大客户的批量首单 | 需合同核验 |
| 合并开票 | 多笔订单合并开具发票 | 拆分为多笔记录 |
| 录入错误 | 金额多写/少写一个0 | 核对后更正 |
| 虚假数据 | 恶意虚报销售业绩 | 上报销售总监处理 |
